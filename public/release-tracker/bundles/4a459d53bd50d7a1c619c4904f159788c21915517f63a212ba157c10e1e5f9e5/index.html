    How this stays accurate

    The collector reads GitHub release events and resolves every published tag to its full source commit. Each complete snapshot has an immutable identity. Published releases, tagged source, branch activity, and feature support remain separate records.

    Artifact digests below are reported by GitHub. The tracker records that metadata; the release's own installation and checksum instructions provide artifact verification. Performance results retain their measured workload and implementation scope.

    Website source reports the latest change under src/, which excludes generated tracker-refresh commits. Broader issue-to-feature reconciliation and a unified documentation/tool-update bundle remain separate work in the release contract.
