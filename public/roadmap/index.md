# The road to Amber V2

Explore the branching roadmap, its release history and supporting implementation evidence. Minecart and agent guidance are the entry point. Parallel trails cover the web foundation, usable components, FrontLoader/assets, persistence, request schemas, scoped performance work and the complete release journey.

Published releases, merged source, evaluation work and proposals retain separate states. Beta.5 is the released web baseline; later repository releases appear in the [ecosystem tracker](/release-tracker/). A release event supplies publication evidence; feature support follows its versioned documentation and acceptance.
